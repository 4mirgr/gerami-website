# وب‌سایت شخصی دکتر گرامی

سایت استاتیک فارسی/انگلیسی، بدون وابستگی اجرایی در صفحات عمومی. محتوای اصلی، ناوبری و منوی موبایل بدون JavaScript کار می‌کنند. فونت سیستمی است؛ درخواست فونت، ردیاب یا فرم شخص ثالث وجود ندارد.

برای **نسخهٔ ترکیبیِ Cloudflare** شامل intmed و AUS، فرمان ساخت `python3 -m pip install -r requirements-cloudflare.txt && python3 scripts/build_cloudflare.py` با خروجی `_site` است. تنظیمات دقیق Cloudflare Pages و انتقال دامنه در [راهنمای Cloudflare](docs/cloudflare.md) آمده است. این دستور برنامه‌ها را از نسخه‌های قفل‌شده دریافت می‌کند، کنترل‌های رسمی محتوا و آزمون‌های اصلی intmed را قبل از تولید خروجی اجرا می‌کند و چیزی منتشر نمی‌کند؛ مخازن اصلی را هم تغییر نمی‌دهد.

منبع AUS واقعی، `4mirgr/immi-arash-amir` است؛ داشبورد بدون ورودِ `immi_AUS` دیگر استفاده نمی‌شود. رابط ورود در `/aus/` به همان Worker موجود متصل می‌شود. اتصال `AUS_APP` و محدودیت موقت OAuth در [راهنمای درگاه AUS](docs/aus-gateway.md) توضیح داده شده‌اند. هیچ کاربر، دیتابیس یا کلید جدیدی ایجاد نمی‌شود.

## اجرای محلی

```sh
cd /workspace/gerami-website
python3 -m http.server 4173 --bind 0.0.0.0
```

پیش‌نمایش: `http://localhost:4173/`. این سرور برای توسعه است، نه میزبانی عمومی.

## بررسی

```sh
node --check js/main.js
node --check js/links.js
python3 scripts/verify.py
git diff --check
```

برای آزمون واقعی مرورگر، سرور محلی را روشن نگه دارید و با Node.js 22 یا جدیدتر و Chromium نصب‌شده اجرا کنید:

```sh
node scripts/browser-check.mjs
```

این آزمون ۸ صفحه را در دو زبان و سه عرض صفحه بررسی می‌کند؛ همچنین ناوبری با صفحه‌کلید، کاهش حرکت، ذخیره‌سازی مسدود، JavaScript غیرفعال و مقصدهای پیکربندی‌شده را کنترل می‌کند. تصویرهای پیش‌نمایش در `/tmp/gerami-desktop.png` و `/tmp/gerami-mobile.png` نوشته می‌شوند. هنگام اجرا در محیط محدود، مجوز مرورگر/اتصال محلی ممکن است لازم باشد.

## تکمیل اطلاعات واقعی

- مقصدهای عمومی را در `js/links.js` وارد کنید: لینکدین، لینک اختصاصی نوبت، ایمیل و شمارهٔ عمومی. مقدار `null` وضعیت غیرفعال و شفاف فعلی را حفظ می‌کند. اسرار، توکن یا اطلاعات خصوصی را در فایل‌های سایت نگذارید.
- دو دکمهٔ مستقیم با مقصدهای `https://drgerami-md.ir/intmed/` و `https://drgerami-md.ir/aus/` در صفحهٔ اصلی و صفحهٔ پروژه‌ها قرار دارند. پیام کنار آن‌ها اعلام می‌کند که اتصال سرویس‌ها هنوز تکمیل نشده است. لینک کارت‌های توضیحی را در `js/links.js` فقط پس از استقرار و بررسی واقعی فعال کنید؛ آن‌ها فقط زیرمسیر همان سایت یا زیرمسیر دامنهٔ `drgerami-md.ir` را می‌پذیرند. پوشهٔ جایگزین یا نسخهٔ ساختگی intmed/AUS ساخته نشده است.
- نام و اطلاعات زندگی‌نامه در HTML است؛ عنوان حرفه‌ای، مدارک، سال‌ها، محل فعالیت و مهارت‌ها را با اطلاعات تأییدشده تکمیل کنید. در هر عبارت دوزبانه، متن فارسی و `data-fa` و `data-en` را با هم ویرایش کنید.
- مقالهٔ واقعی هنوز دریافت نشده است. برای هر مقاله، مخاطب، نویسنده، تاریخ انتشار/بازبینی و منابع را درج کنید. محتوای تخصصی را از آموزش عمومی تفکیک کنید.
- اگر تصویر پرتره اضافه شد، از فایل محلی فشرده با اندازه‌های مشخص و متن جایگزین استفاده کنید. نشان AG فعلی عکس پزشک نیست.

## صفحات

`index.html`، `pages/about.html`، `pages/services.html`، `pages/blog.html`، `pages/projects.html`، `pages/contact.html`، `pages/appointments.html` و مسیر قدیمی `pages/beyond.html`.

مسیرهای فعلی صفحات حفظ شده‌اند. خروجی ترکیبی، `/intmed/` و رابط دارای ورود `/aus/` را می‌سازد. برای فعال‌شدن API واقعی AUS، اتصال به Worker موجود لازم است. پیش از انتقال دامنه، راهنمای Cloudflare و آزمون‌های واقعی هر دو حساب را کامل کنید.

انیمیشن فقط ورود کوتاه صفحه و تغییر رنگ دکمه‌هاست و با `prefers-reduced-motion` خاموش می‌شود. هیچ محتوا یا لینک اصلی برای نمایش به پایان انیمیشن یا بارگذاری JavaScript وابسته نیست.

## طراحی روز/شب و مدیریت محتوا

لوگوی اصلی و تصاویر ارسالی در `assets/` هستند. انتخاب روز/شب در همهٔ صفحات ذخیره می‌شود و انتخاب اولیه تابع دستگاه است. پنل مستقل `/admin/` با Decap CMS، گردش پیش‌نویس/انتشار در Git، مدیریت تصویر، مقاله، CV و تماس اضافه شده است. ورود واقعی به OAuth App اختصاصی و تنظیم اسرار در Cloudflare وابسته است؛ [راهنمای راه‌اندازی](docs/admin.md) را ببینید. کلیدها را در چت یا مخزن وارد نکنید.

بررسی اختصاصی: `node scripts/test_cms_oauth.mjs` و، همراه سرور محلی، `node scripts/test_personal_site.mjs`.

## بازبینی و نگهداری خودکار

فرمان کامل بررسی `python3 scripts/check_site.py --browser` است. ابزارهای مرورگر فقط وابستگی توسعه هستند؛ سایت عمومی همچنان استاتیک و بدون وابستگی npm اجرایی است. با `npm ci --ignore-scripts` و `npx playwright install chromium` ابزارها را آماده کنید؛ مسیر مرورگر از `CHROMIUM_PATH` قابل انتخاب است.

بررسی روزانه و به‌روزرسانی هفتگی آزموده‌شده در `.github/workflows/` تعریف شده‌اند. به‌روزرسانی خودکار فقط نسخهٔ کامل commit دو پروژه روی شاخه‌های مشخص و patch ابزار آزمون را تغییر می‌دهد. تغییر قالب، مسیرها، حساب‌ها و اطلاعات پزشکی خودکار نیست. محتوای تأییدشده از پنل منتشر می‌شود و لینک‌ها/رزومه در سایت اعمال می‌شوند. گزارش و حدود دقیق در [بازبینی سایت](docs/site-review-2026-11-12.md) و قواعد نگهداری در [AGENTS.md](AGENTS.md) آمده‌اند.
