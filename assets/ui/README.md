# Header control artwork

`material-controls.png` was generated with OpenAI image generation on
2026-11-17 for the owner's request to replace the theme and language controls.
It contains three transparent cells: sun, moon, and translation globe.
CSS selects the cells without modifying the original image. The source image
is retained in the workspace's `generated_images` directory.

Icons are decorative. Buttons retain translated accessible names and a
small language destination badge. Forced-color mode has symbolic fallbacks.
