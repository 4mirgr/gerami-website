# Public glass artwork

Generated for this website on 2026-11-17 with the image generation tool, following the owner's Archive.zip visual references. These are bespoke abstract sculptures, not copied UI screenshots or images of clinicians/patients. No text, chart, logo or clinical claim is baked into the artwork.

- `ribbon-day.webp`: pearlescent transparent glass ribbon, ice blue/lilac/blush on a light studio background; central quiet space for HTML text. Source `exec-0feb789b-f008-4c27-aabb-8ba9c4462382.png`.
- `ribbon-night.webp`: matching midnight navy composition with blue/silver/lilac glass reflections. Source `exec-1e033b06-4252-4204-b267-5540e0b6204b.png`.

Both originals were generated at 1536×1024 and retained outside the repository. Web assets are WebP quality 83 (60,554 / 67,958 bytes), with no creative pixel edits. Do not add the original ZIP or multi-megabyte source PNGs to deployment.

The home hero uses the CMS light/dark `wallpaper` setting. A selected custom `background` takes precedence. Admin media includes these two originals for reuse. Text and controls remain real HTML; content is readable with image loading or backdrop blur disabled.
