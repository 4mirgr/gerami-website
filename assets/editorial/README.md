# Telegram photo transport

Format-only JPEG derivatives of the owner's existing approved topic artwork under
`assets/topics`, via `assets/optimized/manifest.json`. No new medical illustration,
patient photograph or textbook figure. JPEG supports Telegram sendPhoto; the public
article retains its optimized WebP. Reproduce with Pillow RGB JPEG quality78,
optimize=True. These files are public artwork, never private editorial uploads.
