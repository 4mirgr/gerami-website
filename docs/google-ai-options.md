# Google AI under the owner's zero-payment requirement

Checked official documentation on 2026-11-16. No Google account, key, billing project or external AI request was created or connected in this stage.

## Suitable first use

Google AI Studio and a Gemini API model with an explicitly available **Free Tier** can assist with outlines, bilingual editing, titles and FAQ drafts for public educational articles. Keep the provider optional and outside the live registration/Clinic request path. Free quotas are limits, not an unlimited/uninterrupted service; no paid fallback, trial credit, billing activation or automatic upgrade is authorized. Do not assume every Gemini model has a free API tier.

Generated medical drafts still need actual physician review, accurate sources, author/review dates and publication approval. AI output is not evidence or a substitute for the site's existing draft/publication rules. Existing sourced drafts can continue to be reviewed without connecting a provider.

## Actual restrictions affecting suitability

- The official unpaid-service terms say submitted content and generated responses may improve Google's products and may be processed by human reviewers. Use only public educational material; do not send patient names, national IDs, phone numbers, records, uploads, credentials or private Clinic content to this free workflow. Regional terms differ for EEA/Switzerland/UK; do not infer the owner's legal region from the website language.
- AI Studio/Gemini API access is region-dependent. Iran is absent from the currently published supported-region list. If the owner's actual region/account is unsupported, do not promise access or attempt to bypass it; keep this provider unconnected. No new Google account is needed just to operate the existing site.
- Google authentication and Google AI are separate products. Adding an AI service does not secure the admin dashboard. This increment uses the existing verified GitHub owner login, preserving independent native Clinic medical roles and avoiding another OAuth configuration.
